## A propos

**Quiz Game** est un projet collectif front-end autour d'un quiz musical interactif.  
L'utilisateur repond a une serie de questions a choix multiples, progresse question par question, puis obtient son score final avec la possibilite de recommencer une partie.

Lien du projet en ligne :  
[https://quiz-patphiletas.vercel.app/](https://quiz-patphiletas.vercel.app/)

## Apercu

- Quiz sur la culture musicale
- Interface simple, lisible et responsive
- Navigation fluide entre les questions
- Score final affiche en fin de partie
- Bouton `Rejouer` pour relancer instantanement une session

## Fonctionnalites

- Injection dynamique des questions depuis JavaScript
- Affichage des reponses sous forme de boutons interactifs
- Verification de la reponse choisie
- Blocage du bouton `Suivant` tant qu'aucune reponse n'est selectionnee
- Comptage du score en temps reel
- Reinitialisation de la partie sans rechargement manuel

## Stack technique

- `HTML5`
- `CSS3`
- `JavaScript` vanilla
- `Vercel` pour le deploiement

## Installation locale

1. Cloner le depot

```bash
git clone <url-du-repo>
```

2. Ouvrir le dossier du projet

```bash
cd PROJET\ QUIZ
```

3. Lancer le projet

Ouvre simplement `index.html` dans ton navigateur.

## Objectifs pedagogiques

Ce projet permet de pratiquer :

- la manipulation du DOM
- les evenements en JavaScript
- la gestion d'un tableau de donnees
- la logique conditionnelle
- la structuration d'une petite application front-end
- le travail en equipe sur un projet web

## Pistes d'amelioration

- Ajouter plusieurs categories de quiz
- Integrer un ecran d'accueil
- Afficher la bonne reponse apres chaque question
- Ajouter un chronometre
- Sauvegarder les meilleurs scores
- Ajouter des animations et transitions supplementaires
